================================================================================
                          1. PROJECT OVERVIEW
================================================================================

MISSION:
  Make learning fun for kids and students through interactive quizzes with
  animations, audio feedback, and rewards system.

TARGET AUDIENCE:
  ┌─────────────────┬────────────┬─────────────────────────────────────────┐
  │ Age Group       │ Ages       │ Features                                │
  ├─────────────────┼────────────┼─────────────────────────────────────────┤
  │ Tiny Tots       │ 4-7 years  │ Visual, Audio, Voice-over, No timer     │
  │ Junior Stars    │ 8-12 years │ Reading-based, Timer, Leaderboards      │
  │ Teen Champions  │ 13+ years  │ Competitive, Advanced, Timed challenges │
  └─────────────────┴────────────┴─────────────────────────────────────────┘

KEY DIFFERENTIATORS:
  • Kid-friendly cartoon animations (Lottie)
  • Audio feedback & voice narration
  • AI-generated questions
  • Offline mode support
  • Age-appropriate UI/UX
  • Gamification with badges & rewards

================================================================================
                            2. TECH STACK
================================================================================

FRONTEND:
  ├── Framework:      React Native + Expo SDK 51
  ├── Language:       TypeScript
  ├── Navigation:     React Navigation v6
  ├── State:          Zustand (with persist)
  ├── Animations:     React Native Reanimated + Lottie
  ├── Audio:          Expo-AV + Expo-Speech
  └── UI:             Custom components + Linear Gradient

BACKEND (Future):
  ├── API:            Node.js + Express / Firebase Functions
  ├── Database:       Firebase Firestore
  ├── Auth:           Firebase Authentication
  └── Storage:        Firebase Storage (for assets)

AI INTEGRATION:
  ├── Primary:        OpenAI GPT-4 API
  ├── Fallback:       Local question bank (offline)
  └── Generation:     Dynamic quiz generation per topic

OFFLINE STORAGE:
  ├── AsyncStorage:   User data, preferences, progress
  ├── FileSystem:     Cached assets, quiz packs
  └── SQLite:         (Future) Large offline datasets
